OAK PARK BARBER SALON — DEMO SITE

FASTEST WAY TO SHARE:
1. Unzip this package.
2. Go to Netlify Drop while signed into Netlify.
3. Drag the entire oak-park-barber-demo folder into the drop area.
4. Copy the generated netlify.app address and send it for approval.

TO UPDATE:
Replace index.html with your newest version, then deploy the folder again from the site's Deploys page.

NOTE:
Several images and fonts are loaded from external web addresses, so the viewer needs internet access.
